### 👨‍💻 Sobre Mim

Sou profissional de Tecnologia atuando de forma integrada entre **Infraestrutura / Suporte de TI** e **Engenharia de Software Full-Stack**. Trabalho na **Pochteca Coremal**, onde participo ativamente tanto da sustentação do ambiente tecnológico corporativo quanto do desenvolvimento de plataformas e automações internas.

- 🎓 **Formação:**
  - 🏛️ Cursando **Engenharia da Computação** na **UNIVESP** *(Universidade Virtual do Estado de São Paulo)*
  - 💻 Cursando **Análise e Desenvolvimento de Sistemas (ADS)** no **SENAC**
- 💼 **Atuação Profissional:**
  - 🏢 **Suporte de TI & Desenvolvimento Interno** na **Pochteca Coremal**
  - Atuação na resolução de chamados técnicos, redes, gestão de acessos e criação de sistemas web corporativos de ponta a ponta.
- ⚡ **Áreas de Foco:**
  - Backend com **Python (FastAPI)**, arquitetura REST e autenticação corporativa (Active Directory / LDAP / JWT).
  - Frontend com **React 18** e **Vite**, focado em interfaces dinâmicas e dashboards operacionais.
  - Integração entre bancos legados (**Oracle ERP**) e bancos em nuvem (**PostgreSQL / Supabase**).
  - Uso prático de ferramentas modernas como **Claude Code** para acelerar o desenvolvimento e integração da API do **Google Gemini** para automação e análise inteligente de dados.
